# GPSS 檢索系統 — 發佈頁

經濟部智慧財產局「GPSS 全球專利檢索系統」官方 Open API 的 Windows 桌面檢索工具：
組合條件檢索（申請人、關鍵字、IPC、日期、代理人、審查委員…）→ 結果清單瀏覽 →
單筆完整書目與請求項 → 批次匯出台帳（CSV／JSON）。

涵蓋 23 個資料庫（台／美／日／歐／韓／中／WIPO／東南亞／其他）。
另附命令列版 `gpss-cli.exe`，可讓你的 AI 助理（Claude、ChatGPT、Copilot…）直接下檢索指令。

**本 repo 只提供安裝檔下載與使用說明**，不含程式原始碼。

> 本軟體為免費軟體、非官方工具，與經濟部智慧財產局（TIPO）無任何隸屬、
> 贊助或背書關係。

## 使用前準備：申請 GPSS API 驗證碼（免費）

1. 到 GPSS 網站（tiponet.tipo.gov.tw/gpss1/gpsskmc/）註冊／登入會員。
2. 站內選單「API → API驗證碼線上申請」提出申請。
3. 約 3 個工作日內 Email 核發 16 碼驗證碼；效期 365 天，到期前可展期。
4. **新核發的驗證碼隔日才生效**——期間 API 會回 500 錯誤，隔天再試即可。
5. 首次啟動程式會跳出「設定」視窗，貼上驗證碼後儲存。

驗證碼只存在本機程式資料夾內的 `config.json`，程式不會上傳到任何地方。
請每人申請自己的驗證碼——配額逐驗證碼計算。

> **重要**：驗證碼無效或過期時**不要重複嘗試**。連續以無效驗證碼呼叫，
> TIPO 會封鎖整台機器的 IP。程式遇到認證錯誤一律不自動重試。

## 主要功能

- **組合條件檢索**：申請人、發明人、代理人、審查委員、名稱、摘要、請求項、
  案號、IPC／CPC、優先權、三種日期區間；欄位內可用 `and`／`or`／`not`。
- **先看筆數再撈**：「查詢筆數」只耗約 30 筆配額，確認範圍合理再檢索或匯出。
- **批次匯出台帳**：CSV（Excel 直開不亂碼）＋ JSON；超過 10,000 筆自動以
  日期切窗分批，可暫停／停止；配額用罄時保留已取回部分。
- **配額顯示**：右上角常駐顯示本時段估餘。
- **送出前檢查**：無效的資料庫／欄位代碼、會被 GPSS 靜默擋下而回假零結果的
  字串，送出前就會攔下並提示。
- **與 S092 審查歷程下載器串接**：匯出的 `appnos.txt` 可直接貼進去下載卷宗。
- **命令列版與 AI 操作**：把 [AI操作指南.md](AI操作指南.md) 整份貼給你的 AI，
  它就能透過 `gpss-cli --json` 檢索並讀取結果。

詳細操作見 [使用說明.md](使用說明.md)（安裝後也可從開始功能表開啟）。

## 配額（TIPO 官方限制）

以「筆數」計，每次呼叫最少扣 30 筆，兩類獨立計算：

| 時段 | 檢索結果 | 單筆案號 |
|---|---|---|
| 上班（週一～五 08:00–18:00） | 時段共 10,000 筆 | 每小時 300／時段 3,000 |
| 下班（其餘時間與假日） | 時段共 30,000 筆 | 每小時 1,000／時段 10,000 |

大批匯出建議排在平日 18:00 後或假日。

## 已知限制（官方 API 範圍，非程式問題）

- 文字檢索只及於名稱／摘要／請求項，無法檢索說明書內文。
- 不支援切截 `*` 與鄰近運算——網頁版的檢索式不能照搬。
- 韓國庫（KPA／KPB／KPD）不提供請求項。
- 單一檢索式上限 10,000 筆（程式會自動切窗處理）。
- GPSS 不提供法律狀態、專利家族、說明書全文、圖式、PDF。

安裝或使用問題請開 [Issue](../../issues)，並註明：程式版本（視窗標題或
`gpss-cli --version`）、Windows 版本、發生步驟與畫面訊息。
可附上輸出資料夾的 `search_log.jsonl`（不含驗證碼）。
**請勿貼出 GPSS 驗證碼，截圖前留意設定視窗。**

驗證碼申請、API 異常或 IP 解封請洽 gpss-service@tipo.gov.tw。
